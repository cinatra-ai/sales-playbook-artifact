# Sales Playbook

The sales motion in writing — discovery questions, qualification rubrics, stage gates, call scripts, objection handling, battlecards, buyer-committee mapping, win/loss patterns, and outreach sequences. The playbook is the operating manual that sellers, sales engineers, and managers execute against on every deal.

## Capabilities

- Capture discovery, qualification, and stage-gate criteria in one document
- Hand sellers a single source of truth for scripts, objections, and battlecards
- Search past playbook versions when refining the current motion
- Attach as reference context when briefing or coaching new reps
