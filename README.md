# Sales Playbook

The sales motion in writing — discovery questions, qualification rubrics, stage gates, call scripts, objection handling, battlecards, buyer-committee mapping, win/loss patterns, and outreach sequences. The playbook is the operating manual that sellers, sales engineers, and managers execute against on every deal.

Install via the Cinatra marketplace. Once installed, attach a sales playbook document (Markdown, plain text, or PDF) to any Cinatra conversation. The artifact recognises files that cover stage-gate criteria, qualification frameworks, call scripts, or objection-handling guides, and makes the playbook available as grounded context for deal-coaching, rep onboarding, and playbook review sessions. A confidence threshold of 0.70 is applied at match time; documents below that threshold are not treated as a sales playbook.

No additional credentials or configuration are required. The artifact accepts `text/markdown`, `text/plain`, and `application/pdf` inputs; no connector or external API is needed. If a document is not recognised, confirm it contains explicit sales-process content (stage definitions, qualification criteria, or call scripts) rather than a standalone battlecard, marketing plan, or ICP description, which are handled by separate artifact types.

## Works with

- Cinatra platform workspaces (any edition)

## Capabilities

- Capture discovery, qualification, and stage-gate criteria in one document
- Hand sellers a single source of truth for scripts, objections, and battlecards
- Search past playbook versions when refining the current motion
- Attach as reference context when briefing or coaching new reps
- Classify an uploaded document as a Sales Playbook with a confidence score
